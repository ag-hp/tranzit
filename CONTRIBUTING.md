# Contributing to TRANZIT

Thank you for contributing to **TRANZIT**!

TRANZIT is a collaborative project developed as part of the **2nd-year DAM Intermodular Project**. Contributions from project members are welcome and help improve the application, its documentation, and its overall quality.

## How can you contribute?

### Report a bug

If you find a problem or unexpected behavior:

1. Check whether the issue has already been reported.
2. Open a new **Issue**.
3. Clearly describe the problem and include the steps needed to reproduce it.
4. Add screenshots or relevant information when useful.

### Suggest an improvement

Have an idea for TRANZIT?

1. Open an **Issue** describing your proposal.
2. Explain the problem it solves and the expected behavior.
3. Discuss the proposal with the project team before implementing major changes.

### Submit code

For development work:

1. Create a new branch from `main`.
2. Use a descriptive branch name, for example:
   
   ```text
   feature/nfc-reader
   feature/push-notifications
   fix/notification-error
   docs/update-readme
